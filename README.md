# Mika's Woodcutter Extension: Stonecutter parity for wood blocks
A datapack that extends Minecraft's stonecutter to accept wood blocks, facilitating wood item crafting.
Wood items can be obtained both using logs as well as planks.

## Wood Variants
- Oak *finished*
- Spruce *finished*
- Birch *finished*
- Jungle *finished*
- Acacia *finished*
- Dark Oak *finished*
- Mangrove *finished*
- Cherry *finished*
- Pale Oak *finished*
- Crimson *finished*
- Warped *finished*
- Bamboo *unfinished*
-

Currently supports Minecraft Java Edition 26.1
